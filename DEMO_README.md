# 🎬 NIFTY 50 Analyzer - Interactive Quick Start Demo

This is an **interactive visual guide** that walks you through using the NIFTY 50 Stock Analyzer step-by-step.

## 🚀 How to Open the Demo

### Windows
Double-click: `open_demo.bat`

### Mac/Linux
Double-click: `open_demo.sh`

### Or Manually
Open `QUICKSTART_DEMO.html` in any web browser (Chrome, Firefox, Safari, Edge, etc.)

The demo includes:

### 🎯 Two Interactive Workflows

1. **🌐 Web Interface (Streamlit App)**
   - Step-by-step guide to using the Streamlit web interface
   - Interactive controls and live results
   - Perfect for beginners and exploratory analysis

2. **⚡ Command Line (Standalone)**
   - Quick guide to one-click batch processing
   - Automated report generation
   - Best for regular, scheduled analysis

## 📖 What to Do After Watching

After going through the demo:

1. **Choose Your Method**: Decide between Streamlit (web) or standalone (command line)
2. **Prepare Your Data**: Fill in the template CSV files with your data
3. **Run the Analyzer**: Follow the exact steps shown in the demo
4. **Explore Results**: Check the outputs folder for your reports
5. **Iterate**: Try different configuration settings

## 🎯 Real Quick Start (After Demo)

### For Streamlit (Web Interface):
```bash
streamlit run app_enhanced.py
# Navigate to "🎯 NIFTY 50 Analyzer" tab
```

### For Standalone (Command Line):
```bash
# Windows
cd nifty50_analyzer
run_analyzer.bat

# Mac/Linux
cd nifty50_analyzer
./run_analyzer.command
```
