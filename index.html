📈 NSE/BSE Stock Market Scraper

Extract circulars, reports, and announcements with ease - No coding required!

👋 Welcome!

This tool helps you automatically download stock market data from NSE (National Stock Exchange) and BSE (Bombay Stock Exchange) websites. Whether you're a researcher, analyst, or enthusiast, you can collect historical data in just a few clicks!

✨ Great News! We now have an easy-to-use web interface. No programming knowledge needed!

🚀 Quick Start

  1. Install Python
    Download from python.org (It's free and easy!)
  2. Launch the Application
    Windows: Double-click start.bat
    Mac/Linux: Run ./start.sh in Terminal
  3. Use the Web Interface
    Your browser will open automatically. Just click buttons to select what you want!
  4. Download Your Data
    Get your data in CSV, JSON, or Excel format with one click!

🆘 Troubleshooting

Application won't start?

  • Make sure Python is installed: Run python --version
  • Install dependencies: pip install -r requirements.txt
  • Check internet connection

No data returned?

  • Verify NSE/BSE websites are accessible
  • Check the logs/ folder for error details
  • Try a shorter time range (e.g., 7 days)

Browser didn't open?

Manually open your browser and go to: http://localhost:8501
