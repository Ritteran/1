⚡ Command Line Workflow

1

📝 Prepare Your Data Files

Navigate to the nifty50_analyzer/inputs/ folder and prepare your data:

prices.csv

Copy prices_template.csv → prices.csv
Fill with 1 year (252 days) of daily closing prices

fundamentals.csv

Copy fundamentals_template.csv → fundamentals.csv
Fill with latest financial ratios

sector_mapping.csv

✅ Already complete!
No changes needed

2

⚙️ Configure Settings (Optional)

Edit config.yml to customize:

# Risk-free rate (e.g., 10Y G-Sec yield) risk_free_rate: 0.065 # Composite score weights weights: financial_strength: 0.40 growth_efficiency: 0.30 risk_adjusted_return: 0.30 # Signal thresholds signals: buy_threshold: 80 # Top 20% avoid_threshold: 20 # Bottom 20%
3

🚀 Run the Analyzer

Double-click the launcher for your operating system:

🪟 Windows

Double-click:
run_analyzer.bat

🍎 Mac

Double-click:
run_analyzer.command

🐧 Linux

Double-click or run:
./run_analyzer.command

✨ Key Features

📊 Exact Calculations

Log returns, annualized volatility (σ × √252), and precise Sharpe ratios

🎯 Sector Benchmarking

9 sectors with industry-specific ideal ratio ranges

🔍 Smart Signals

Buy/Hold/Avoid with confidence levels and detailed explanations

⚠️ Risk Monitoring

6 risk flags: volatility, debt, ROE, NPA, returns, margins

📈 Composite Scoring

40% financial + 30% growth + 30% risk-adjusted returns

🛡️ Data Safety

No interpolation or data filling - only real data used

📄 Multiple Outputs

HTML report + 3 CSV files for different use cases

⚙️ Fully Configurable

Adjust thresholds, weights, and risk-free rate

💡 Pro Tips

🎯 Start with Defaults

The 40/30/30 weights and 80/20 thresholds are well-tested. Start here and adjust based on results.

📊 Update Risk-Free Rate

Set this to the current 10-year government bond yield for accurate Sharpe ratios.

🔄 Regular Updates

Re-run analysis monthly or quarterly with fresh data to track changes over time.

📈 Compare HTML Reports

Save HTML reports from different dates to see how signals evolve.

⚠️ Check Risk Flags

Even BUY signals can have 1 risk flag. Read explanations carefully!

📋 Use Detailed CSV

Import into Excel for custom sorting, filtering, and pivot tables.
